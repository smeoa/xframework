# 项目规则

- 禁止一切无用废话,禁止一切假设,禁止一切猜测
- 任何任务执行后必须自动完成有效性验证，确保结果正确、完整、可追溯，**禁止未验证就结束对话或终止流程**。验证不通过则自动修正重试，直至通过
- 临时代码生成后，必须立即删除，不能保留在项目中
- **注意**：`request.js` 已自动处理 camelCase ↔ snake_case 转换，无需手动处理。
- 所有 API 调用都必须使用 `request.js` 函数，不能直接使用 fetch 等其他库。
- 所有请求都使用POST方法，包括创建、更新、删除等操作。
- 修改代码后必须进行语法检查，确保代码质量。
